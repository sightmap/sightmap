New `sightmap-webmcp` skill: turn a mapped site into WebMCP tools. It guides the loop from walking user-goal trajectories with the browser CLI (component queries, network traces), through authoring a `webmcp.tools.yaml` manifest against the corpus, to generating and live-verifying a publishable `document.modelContext` tool bundle with the new `webmcp/` codegen adapter in the sightmap repo. Ships in the plugin, the embedded skills (`sightmap skills install`), and this package.
